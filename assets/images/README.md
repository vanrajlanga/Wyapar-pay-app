# Images Directory

This directory contains all image assets used throughout the WyaparPay application.

## Subdirectories

### `/ui/` - User Interface Images
Contains UI elements, backgrounds, patterns, and decorative images.

**Examples:**
- Background patterns and textures
- Decorative elements
- UI component backgrounds
- Loading animations frames
- Empty state illustrations

**Naming Convention:**
- `background-pattern-*.png`
- `ui-element-*.svg`
- `decoration-*.png`

### `/screenshots/` - App Screenshots
Contains screenshots for documentation, marketing, and app store submissions.

**Examples:**
- App store screenshots
- Documentation images
- Marketing materials
- Feature demonstrations
- User flow screenshots

**Naming Convention:**
- `screenshot-{screen-name}-{device}.png`
- `feature-{feature-name}-demo.png`
- `app-store-{platform}-{size}.png`

### `/placeholders/` - Placeholder Images
Contains placeholder images for development and testing.

**Examples:**
- User avatar placeholders
- Product image placeholders
- Loading placeholders
- Error state images
- Default images

**Naming Convention:**
- `placeholder-{type}-{size}.png`
- `default-{element}-{variant}.svg`
- `loading-{context}-placeholder.png`

## File Guidelines

### Formats
- **PNG**: For images requiring transparency
- **JPG**: For photographs and complex images
- **SVG**: For scalable graphics and icons
- **WebP**: For optimized web delivery (when supported)

### Sizes
- Provide multiple resolutions for different screen densities
- Use appropriate sizes for different contexts
- Optimize file sizes for mobile performance

### Quality
- Maintain high quality for marketing materials
- Optimize for performance in app usage
- Ensure accessibility compliance
