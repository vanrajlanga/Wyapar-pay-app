# Placeholder Images

This directory contains placeholder images for development and testing purposes.

## Available Placeholders

### User Avatars
- `user-avatar-placeholder-32x32.png` - Small user avatar
- `user-avatar-placeholder-64x64.png` - Medium user avatar  
- `user-avatar-placeholder-128x128.png` - Large user avatar

### Product Images
- `product-placeholder-200x200.png` - Square product image
- `product-placeholder-300x200.png` - Rectangular product image
- `service-placeholder-150x150.png` - Service icon placeholder

### UI Elements
- `loading-placeholder-100x100.png` - Loading state placeholder
- `empty-state-placeholder-300x200.png` - Empty state illustration
- `error-placeholder-200x150.png` - Error state placeholder

### Business Categories
- `mobile-recharge-placeholder.png` - Mobile recharge service
- `electricity-bill-placeholder.png` - Electricity bill service
- `credit-card-placeholder.png` - Credit card service
- `loan-repayment-placeholder.png` - Loan repayment service

## Usage Guidelines

### Development
- Use placeholders during development to test layouts
- Replace with actual images before production
- Maintain consistent aspect ratios

### Testing
- Use for UI testing and layout verification
- Ensure responsive behavior with different image sizes
- Test loading states and error handling

### Accessibility
- Provide alt text for all placeholder images
- Ensure sufficient contrast for visibility
- Use descriptive filenames for context
