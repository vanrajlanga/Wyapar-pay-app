# Icons Directory

This directory contains all icon assets for the WyaparPay application.

## Subdirectories

### `/ui/` - User Interface Icons
Contains icons used in the user interface for navigation, actions, and interactions.

**Examples:**
- Navigation icons (home, profile, settings)
- Action icons (add, edit, delete, save)
- Status icons (success, error, warning, info)
- Form icons (calendar, dropdown, checkbox)
- Control icons (play, pause, close, minimize)

**Naming Convention:**
- `nav-{name}.svg`
- `action-{name}.svg`
- `status-{name}.svg`
- `control-{name}.svg`

### `/business/` - Business-Related Icons
Contains icons related to financial services, payments, and business operations.

**Examples:**
- Payment method icons (credit card, UPI, wallet)
- Service category icons (mobile recharge, electricity, gas)
- Transaction type icons (credit, debit, transfer)
- Security icons (lock, shield, verified)
- Feature icons (QR code, NFC, biometric)

**Naming Convention:**
- `payment-{method}.svg`
- `service-{category}.svg`
- `transaction-{type}.svg`
- `security-{feature}.svg`

### `/social/` - Social Media Icons
Contains icons for social media integration and sharing features.

**Examples:**
- Social platform icons (Facebook, Twitter, Instagram, LinkedIn)
- Sharing icons (share, copy link, embed)
- Communication icons (email, SMS, WhatsApp)
- Social action icons (like, comment, follow)

**Naming Convention:**
- `social-{platform}.svg`
- `share-{method}.svg`
- `communication-{type}.svg`

## Icon Guidelines

### Design Principles
- **Consistency**: Maintain consistent stroke width and style
- **Clarity**: Ensure icons are recognizable at small sizes
- **Accessibility**: Provide sufficient contrast and clear shapes
- **Scalability**: Design for multiple sizes and contexts

### Technical Specifications
- **Format**: SVG preferred for scalability
- **Size**: Provide multiple sizes (16px, 24px, 32px, 48px)
- **Style**: Consistent with Material Design or chosen design system
- **Color**: Support both light and dark themes

### Usage
- Use semantic names that describe function, not appearance
- Group related icons in subdirectories
- Maintain consistent naming conventions
- Document icon meanings and usage contexts
