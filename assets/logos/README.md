# Logos Directory

This directory contains all logo variations and formats for the WyaparPay brand.

## Subdirectories

### `/variants/` - Logo Variations
Contains different versions of the WyaparPay logo for various use cases.

**Examples:**
- **Horizontal Logo**: Full logo with text arranged horizontally
- **Vertical Logo**: Logo with text stacked vertically
- **Icon Only**: Just the symbol/mark without text
- **Full Logo**: Complete logo with tagline
- **Monochrome**: Single-color versions for special applications
- **Reversed**: White/light versions for dark backgrounds

**Naming Convention:**
- `wyaparpay-logo-horizontal.svg`
- `wyaparpay-logo-vertical.svg`
- `wyaparpay-icon-only.svg`
- `wyaparpay-logo-full.svg`
- `wyaparpay-logo-monochrome.svg`
- `wyaparpay-logo-reversed.svg`

### `/formats/` - File Formats
Contains the same logo variations in different file formats for various applications.

**Examples:**
- **SVG**: Scalable vector format for web and print
- **PNG**: Raster format with transparency support
- **PDF**: Print-ready format for documents
- **EPS**: Vector format for professional printing
- **JPG**: Compressed format for web use (when transparency not needed)

**Naming Convention:**
- `wyaparpay-logo-horizontal.svg`
- `wyaparpay-logo-horizontal.png`
- `wyaparpay-logo-horizontal.pdf`
- `wyaparpay-logo-horizontal.eps`

## Logo Usage Guidelines

### Size Requirements
- **Minimum Size**: Maintain readability at smallest use
- **Maximum Size**: Ensure quality at largest applications
- **Clear Space**: Maintain appropriate spacing around logo
- **Proportional Scaling**: Keep aspect ratios consistent

### Color Applications
- **Primary Colors**: Use brand colors for primary applications
- **Monochrome**: Use for single-color applications
- **Reversed**: Use light versions on dark backgrounds
- **Contextual**: Adapt colors for different contexts

### Usage Contexts
- **Digital**: Web, mobile apps, social media
- **Print**: Business cards, letterheads, marketing materials
- **Signage**: Physical signs, banners, displays
- **Merchandise**: Branded items, promotional materials

### Brand Compliance
- **Consistency**: Use approved variations only
- **Modifications**: Do not alter colors, proportions, or spacing
- **Placement**: Follow brand guidelines for positioning
- **Context**: Choose appropriate variant for each use case
