# WyaparPay Color Guidelines

## Primary Colors

### Wyapar Blue (#00D4FF)
- **Usage**: Primary brand color, CTAs, highlights
- **Context**: Buttons, links, active states, brand elements
- **Accessibility**: Ensure sufficient contrast on light backgrounds

### Wyapar Dark (#0F0F23)
- **Usage**: Primary background, text on light backgrounds
- **Context**: Dark themes, primary backgrounds, main text
- **Accessibility**: High contrast with white text

### Wyapar Cyan (#00BCD4)
- **Usage**: Secondary brand color, accents
- **Context**: Secondary buttons, accents, hover states
- **Accessibility**: Good contrast with dark backgrounds

## Semantic Colors

### Success (#4CAF50)
- **Usage**: Success states, confirmations, positive actions
- **Context**: Success messages, completed states, positive indicators
- **Accessibility**: Good contrast for text and icons

### Warning (#FF9800)
- **Usage**: Warning states, caution messages
- **Context**: Warning alerts, pending states, attention-grabbing elements
- **Accessibility**: Ensure text readability

### Error (#F44336)
- **Usage**: Error states, destructive actions
- **Context**: Error messages, delete buttons, critical alerts
- **Accessibility**: High contrast for important messages

### Info (#2196F3)
- **Usage**: Informational messages, neutral states
- **Context**: Info alerts, neutral actions, informational content
- **Accessibility**: Good contrast for readability

## Usage Guidelines

### Contrast Requirements
- **AA Compliance**: Minimum 4.5:1 contrast ratio for normal text
- **AAA Compliance**: Minimum 7:1 contrast ratio for enhanced accessibility
- **Large Text**: Minimum 3:1 contrast ratio for large text (18pt+)

### Color Combinations
- **Primary + White**: High contrast, professional
- **Dark + Cyan**: Modern, tech-focused
- **Success + Dark**: Clear positive feedback
- **Error + White**: Clear negative feedback

### Accessibility Notes
- **Color Blindness**: Don't rely solely on color for information
- **High Contrast**: Provide high contrast mode support
- **Focus States**: Ensure focus indicators are visible
- **Text Readability**: Test readability across all color combinations
